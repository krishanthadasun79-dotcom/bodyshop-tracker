Replace the existing site files with all files in this package. Then on the phone: close Bodyshop Tracker; open the site once in Chrome/Safari and wait for it to load; if the installed home-screen shortcut still shows the previous icon, remove the old shortcut/app from the home screen and use Add to Home screen / Install app again. This is necessary because mobile launchers can retain the old installed icon independently of the website cache. Existing app data is stored in browser storage and is not included in this ZIP. Back up app data before changing deployed files.
